# Portfolio Website 🌐

This is my personal **DevOps Portfolio Website** built with **React + Tailwind CSS** to showcase my projects, skills, and experiences.

## 🚀 Features
- Responsive design with Tailwind CSS
- Smooth animations using Framer Motion
- Project showcase section connected to backend API
- About Me, Skills, and Contact sections
- Deployed on AWS EC2 with Nginx reverse proxy
- Custom domain with SSL: [vipdevo.xyz](https://vipdevo.xyz)

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Framer Motion
- **Build Tools:** Node.js, npm
- **Deployment:** Docker, Nginx, GitHub Actions CI/CD
- **Hosting:** AWS EC2

## 📦 Installation
```bash
# Clone repo
git clone https://github.com/vipin-thomas/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run locally
npm start
```

## 🔧 Build
```bash
npm run build
```
